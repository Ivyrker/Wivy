Картинки для заметок об обновлениях.

1. Положите картинку сюда (png, jpg, webp, gif или avif).
2. Впишите её имя в поле "images" нужной версии в patchnotes.json (лежит рядом с main.js):

   { "version": "1.1.0", "date": "2026-12-01", "title": "Заголовок",
     "items": ["Что изменилось", "И ещё"], "images": ["1.1.0-player.png"] }

Новые версии пишите в начало списка "entries". Текст можно писать по-английски:
перевод берётся из languages/ru.json (добавьте туда фразу, если нужен перевод).
